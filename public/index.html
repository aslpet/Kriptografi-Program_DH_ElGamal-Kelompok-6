🗺️ Peta Peran Kriptografi End-to-End (Tabel Bagian 5) 14 Tahap Terverifikasi
Tahap Algoritma Operasi Matematis Input & Output Lokasi Eksekusi
1. Setup Parameter DH/ELGAMAL Prima aman p = 2q + 1, generator g = h^2 mod p (orde q) Bit → (p, q, g) Server / EA
2. Keygen EA ELGAMAL x ∈ [2, q-1] (rahasia), h = g^x mod p (publik) Parameter → (x, h) Backend EA (Private x)
3. Handshake Voter DH a ∈ [2, q-1], A = g^a mod p Parameter → (a, A) Browser Klien
4. Handshake Server DH b ∈ [2, q-1], B = g^b mod p A → (b, B) Server
5. Kunci Sesi Bersama DH Voter: K = B^a mod p, Server: K = A^b mod p B atau A → K identik Browser & Server
6. Penurunan Kunci CHANNEL encKey, macKey = KDF(K, transcript) via SHA-256 K, Transkrip → 2 Kunci Browser & Server
7. Enkripsi Suara ELGAMAL Vektor m_i = g^{v_i}, c1_i = g^{k_i}, c2_i = m_i · h^{k_i} mod p Pilihan → [(c1, c2)] Browser Klien
8. Pengamanan Saluran CHANNEL Counter-mode Keystream XOR + HMAC-SHA256 Encrypt-then-MAC Payload → {seq, ct, tag} Browser Klien
9. Kotak Suara Anonim BALLOT BOX Verifikasi HMAC, tolak double-voting atomik, simpan tanpa ID Paket → Receipt SHA-256 Ballot Box Publik
10. Agregasi Homomorfik ELGAMAL C1_j = ∏ c1, C2_j = ∏ c2 mod p V Ballot → 3 Pasang Agregat Server (Publik)
11. Dekripsi Total EA ELGAMAL s = C1^x mod p, g^T = C2 · s^{-1} mod p x, Agregat → g^T Backend EA
12. Pemulihan Suara T DLOG Cari T ∈ [0..V] di mana g^T == gT g^T → Perolehan Suara Server
13. Verifikasi Konsistensi AUDIT Audit matematis: ∑ T_j == V (total suara == total ballot) Hasil → Valid / Tidak Halaman Hasil
14. [BONUS] Autentikasi DH SIGNATURE Server menandatangani transkrip DH: g^H == ys^r · r^s mod p Transkrip → Anti-MITM Browser & Server
